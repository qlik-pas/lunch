# lunch

Today-first lunch view for seven Lund places with a dish of the day (Edison,
Bricks, Smaka på Kina, Kantin, Eatery, Troppo, Matstudio Kungsmarken). A GitHub Action scrapes the menus on
weekdays (Monday a few times through late morning, when the new week's menu
lands, plus a midday pass Tue–Fri) and commits `lt.json` only when a menu
actually changed; `index.html` renders whichever day it is.

Ten more places with a standing menu rather than a dish of the day are listed
by hand in `index.html` (`FIXED_PLACES`) — a collapsed "Fast meny" section, and
all of them are on the "Vad blir det?" wheel.

The "Copy todays choices" button (next to the day heading) copies the day's lunch to the clipboard as
a Slack-ready English post. The English dish names are produced in `scraper.py`
(an `en` field per restaurant in `lt.json`) and only re-done when a menu changes:
with GitHub Models through the workflow's own token. If it doesn't answer, the
button falls back to the Swedish text. Places with a standing menu are listed last. Run the workflow manually with *retranslate* ticked to redo them all.

## Files
- `index.html` — the page (fetches `lt.json`, falls back to a baked-in snapshot)
- `scraper.py` — fetches the seven sources, writes `lt.json`
- `lt.json` — current menus (regenerated by the Action)
- `.github/workflows/lunch-scrape.yml` — scheduled scrape + commit-on-change

## Run locally
    pip install requests beautifulsoup4 playwright==1.63.0
    playwright install chromium   # only needed once, for the Eatery source
    python scraper.py

## Deploy
1. Settings → Actions → General → Workflow permissions → **Read and write**
2. Settings → Pages → Deploy from branch → `main` / root
3. Actions tab → run **Scrape lunch menus** once
4. Open `https://qlik-pas.github.io/lunch/`

Eatery's menu is a client-rendered board (menu.pej.io) and needs headless
Chromium to scrape — see `scraper.py`'s `fetch_rendered_text`. If the URL
moves, set `EATERY_MENU_URL` in the workflow.
Kantin is scraped from kantinlund.se (robots-disallowed; swap to a mirror if it 403s).
